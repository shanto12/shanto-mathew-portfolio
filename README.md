# Shanto Mathew Portfolio

Personal website for `ShantoMathew.com`, built to present Shanto's public-safe achievements, skills, and Netlify-hosted AI/security demos.

Live URL after deploy: `https://shanto-mathew-portfolio.netlify.app`
Custom domain target: `https://ShantoMathew.com`

## What It Includes

- Portfolio landing page for AI security automation and agentic AI work.
- Live demo gallery with links to the Netlify-hosted demos.
- Skills matrix for AI engineering, SOAR/XSOAR/XSIAM, Python/API platform work, and production demo shipping.
- Netlify Functions backend:
  - `/api/health` for deployment verification.
  - `/api/contact` for contact workflow validation.
- Netlify Forms contact capture in production.

## Run Locally

```bash
npm install
npm run verify
npm run e2e
npm run dev
```

## Public Data Policy

The site intentionally excludes phone number, birthdate, full home address, identity documents, exact recruiter rates, private recruiter history, internal client workflows, and secrets.
