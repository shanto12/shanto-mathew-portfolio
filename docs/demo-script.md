# Demo Script

## 90 Seconds

This is my personal portfolio at `ShantoMathew.com`. The first screen positions me around AI security automation, agentic AI, and SOAR/XSOAR/XSIAM work. The demo gallery links directly to the deployed Netlify apps, so a recruiter or hiring manager can open each project and test it live.

The important part is that this is not just a resume page. It has a small backend health endpoint, a contact workflow, clear data provenance, and a public-safe policy about what is intentionally excluded.

## 5 Minutes

1. Open the hero and explain the positioning.
2. Show the achievement strip and skills matrix.
3. Filter the demo gallery by Security AI, Voice AI, Revenue AI, and Creative Systems.
4. Open a live Netlify demo in a new tab.
5. Show `/api/health` and the evidence matrix.
6. Submit the contact form test flow.
