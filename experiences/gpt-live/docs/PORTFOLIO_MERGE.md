# Portfolio design and voice merge

The approved visual foundation is the currently deployed Fieldwork portfolio at https://shantomathew.com/. Its source is `/Users/shanto/Documents/Playground/portfolio-reimagined-2026/expanded-site`, verified byte-for-byte against the live HTML, JavaScript and CSS before this merge. The older nine-project voice fork and older React portfolio are historical versions, not the production design to preserve.

This release combines the current fourteen-project design, two portraits, detailed case studies, project selection, image inspection and updated career data with the existing Pip voice guide. The first screen is tightened to bring the portrait, positioning and project invitation into view without an oversized empty container. Pip keeps its established personality, generated opening, bounded page tools and session-only presentation changes.

Deployment is limited to https://shanto-portfolio-live.netlify.app/. The custom domain and existing Netlify project must remain unchanged until Shanto explicitly approves the preview. The original design is already independently available at https://shanto-fieldwork-portfolio.netlify.app/ and its immutable release at https://6aa1d197f09280f08595e246--shanto-fieldwork-portfolio.netlify.app/; both returned HTTP 200 with the same HTML hash as the custom domain before implementation.

The source project has no authentication, payments, submission forms or provisioning jobs. Those are not implied by this portfolio merge. Linked external demos keep their individual operating boundaries. User/API spending remains bounded by the current explicit authorization; changing design does not authorize a spending increase.

The release evidence matrix will record actual coverage, including which checks used simulated API responses, actual provider calls, and the user's real Chrome profile. Custom-domain publication remains a separate approval step.
